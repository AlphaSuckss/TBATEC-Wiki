Every command starts with <span class="thing">/tbatec</span> and needs operator permission (level 2). <span class="thing">/tbatec help</span> lists most of them.

**manacore &lt;players&gt; show**: rank, mana and refinement<br>**... fill / empty**: mana to full or to nothing<br>**... setMana / addMana &lt;n&gt;**: set or add mana

## Mana Cores

**... mastery**: list elemental mastery<br>**... setMastery &lt;element&gt; &lt;0-100&gt;**: set it<br>**... advanceColor / advanceStage**: move the core up, skipping the trials<br>**... setColor / setStage**: set the rank directly

## Heritage

**origin &lt;players&gt; show**: their heritage<br>**... reroll**: the same as a Crystal of Rebirth<br>**... reroll affinities**: keep the race and core colour; roll the core, elements, gifts and class again<br>**... race &lt;race&gt;**: any race, asura and wraith included<br>**... core true / false**: give or take a core

**... element add / remove &lt;element&gt;**<br>**... class augmenter / conjurer**<br>**... deviant add / remove &lt;art&gt;**: removing an art also sets its practice back to half the threshold<br>**... practice &lt;element&gt; &lt;amount&gt;**: adds practice, which can awaken arts

## Gates

**gates list**: every known gate<br>**gates discover &lt;players&gt;**: reveal every gate<br>**gates forget &lt;players&gt;**: forget them all
